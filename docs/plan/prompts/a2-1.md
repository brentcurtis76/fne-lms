## Table spec (PLAN.md A2 [A1]–[A2] — implement exactly)

`public.pasantias_leads`: `id uuid PK DEFAULT gen_random_uuid()`; `cohort text
NOT NULL`; `first_name`, `last_name`, `email`, `email_normalized`, `institution`
all `text NOT NULL`; `phone`, `role_title`, `message`, `source_path`,
`utm_source`, `utm_medium`, `utm_campaign`, `notes` text nullable; `num_people
integer` CHECK (NULL or 1–60); `status text NOT NULL DEFAULT 'new'` CHECK in
(`new`,`contacted`,`converted`,`dismissed`); **`consent_accepted_at timestamptz
NOT NULL` (NO default)**; `consent_notice_version text NOT NULL`;
**`marketing_opt_in boolean NOT NULL DEFAULT false`**, `marketing_opt_in_at
timestamptz`, `marketing_notice_version text` with CHECK enforcing the two

timestamptz`; `created_at`/`updated_at` defaults + `set_updated_at` trigger;
CHECK `email_normalized = lower(btrim(email)) AND email_normalized <> ''`;
UNIQUE `(email_normalized, cohort)`; indexes on `(status)` and
`(created_at DESC)`.
