## The defect

The render contract can pass on a leaf that is hardcoded. **PM-proven on this exact
head:**

1. Replaced `{formatDays(immersionDays)}` in the page with the literal `2,5`.
2. Ran the guard — **15/15 passed.**
3. Changed **both** immersion schools in the module to `immersionDays: 4`, rebuilt,
   served, and fetched the page. It rendered **"2,5 días cada una"** — the stale
   hardcoded value. The module said 4; the page said 2,5; the guard was green.

**Why it passes.** The contract mutates one leaf at a time and asserts the render
*changed*. When it mutates `immersionSchools[0].immersionDays`, the two schools stop
agreeing, `uniformImmersionDays()` returns `null`, and the whole "días cada una" clause
disappears. The render did change — so the contract concludes the leaf is wired. It
changed for the wrong reason.

This is not specific to `immersionDays`. **Any leaf read through a conditional, an
aggregate, a uniqueness check or a length comparison can satisfy "the render changed"
by collapsing rather than by re-rendering the new value.** `uniformImmersionDays` is
simply the one that exists today.

## The fix

**"The render changed" is the wrong assertion. "The render contains the new value" is
the right one.**

Where a leaf's value is renderable, assert the mutated value **appears** in the output —
and, where it was present before, that the original no longer does. A leaf that merely
makes something vanish has not been shown to be wired.

Some leaves genuinely aren't directly renderable — a boolean read as a flag, a `tier`
string compared rather than printed, an `id` used in a testid. Those cannot satisfy a
containment assertion. **Do not quietly fall back to "changed" for them**: classify them
explicitly, with the reason, in the same declared-gap machinery r3 already built for
`EXPECTED_GAPS`, so the weaker check is visible rather than assumed. If a leaf can be
made renderable-checkable by asserting on the element that consumes it, prefer that over
declaring a gap.

Then **re-derive**: after the fix, some leaves that previously passed will fail because
they were only ever passing vacuously. That is the point — expect it, and report exactly
which ones moved and why.
