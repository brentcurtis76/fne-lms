## B1 — a leaf's old value only has to become *rarer*, not disappear

`__tests__/pages/pasantias-hardcoded-cohort.test.ts:658-660`, inside `provesRendered`:

```js
return renderedForms(leaf.value)
  .filter((form) => countUnmutated(baseline, form) > 0)
  .every((form) => countUnmutated(output, form) < countUnmutated(baseline, form));
```

**`<`, not `=== 0`.** So a fact printed at two sites, hardcoded at one, still passes: the
baseline has two occurrences, the mutated render has one, one is fewer than two, and the
leaf is classified `rendered` while the literal sits there going stale.

The comment directly above states the correct intent — *"a page that renders the module
and restates the same fact as a stale literal would otherwise satisfy the containment half
on the live copy alone"* — so this is an implementation that does not do what its own
docstring says.

### The route, which is not `=== 0`

Requiring zero on its own is wrong and the current `<` is presumably why: sibling leaves
legitimately share values. El Puig and Les Vinyes both hold `'Infantil, primaria y ESO'`
(the r4 case), so mutating one leaves the other's copy on the page and a naive
"must be gone" fails a correct page.

**The machinery to do this properly already exists in the file.** `quietModule()` marks
every other string leaf, which is exactly how r5's `printsStaleSize` and r6's fragment
rule tell one site's copy from another's. On a quiet surface, a surviving occurrence of
this leaf's old value can only be a literal the page typed. Require **zero** there.

That is a suggestion from someone who has read the file, not a specification. If you find
something better, take it and say why. What is not negotiable:

1. A fact printed at N sites, hardcoded at any one of them, **fails by name**.
2. A correct page still passes — including leaves whose siblings hold the same value.
3. Whatever leaves start failing under the stricter rule are **fixed or declared with a
   reason you checked against the code**. Expect movement: r5's equivalent re-derivation
   moved twelve leaves, and every one of them had been passing vacuously.
4. A permanent negative control for the two-site case, using a real page site.
