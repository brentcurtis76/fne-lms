every test here."* The PM took that seriously enough to measure it, and it is worse than
one filter.

`get` trap returns `vi.fn(() => new Proxy({}, handler))` for **every** property. So
`.eq(...)` accepts any arguments and returns the same canned row per table, and
`buildClient` keys results by table name alone. Filter arguments are invisible to every
assertion in both suites.

reaches that branch** whenever the session has *any* attendee row, expected or not,
theirs or not. Result:
