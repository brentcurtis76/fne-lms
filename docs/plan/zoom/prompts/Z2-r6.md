## 2. SCOPE — chunk Z2-2b: the two human surfaces

**S1 — "Generar reunión Zoom" in the scheduler** (`pages/admin/sessions/create.tsx`).

- A checkbox, es-CL label **"Generar reunión Zoom"**, visible **only** when
  `modality` is `online` or `hibrida` **and** `isFeatureEnabled(FeatureFlags.ZOOM_MEETINGS)`
  is true. Off by default.
- When checked: the manual `meeting_link` field is hidden **and** the client-side
  "meeting_link required" validation at `:478-486` no longer applies (the server already
  exempts it — the client must agree, or the form blocks a request the API would accept).
  Show a short es-CL helper line saying the link is generated when the session is
  approved.
- `handleModalityChange` must clear the flag when modality moves to `presencial`,
  exactly as it already clears `meeting_link` — otherwise a hidden checked box submits.
- Both payload builders send `is_zoom_managed`.
- `data-testid` on the checkbox (repo convention; `npm run lint:testid` is advisory).

**S2 — the managed join on the interstitial** (`pages/meet/session/[id].tsx` +
`lib/utils/session-meet-access.ts` + a new component).

- Add `is_zoom_managed` to the `MeetSessionView` select and type.
- **Managed session ⇒ a new `JoinMeetingButton`, not the legacy `<a href>`.** The button
  `POST`s to `/api/meet/session/[id]/join` and acts on the response:
  - `{mode:'link'}` → open `join_url` in a new tab (`rel="noopener noreferrer"`).
  - `{mode:'pending'}` → es-CL **"Enlace en preparación"** (plan §8's exact promise), and
    the button stays available to retry.
  - `403` → render the server's message verbatim; it is already es-CL and already
    distinguishes the two denials. Do not substitute your own copy.
  - `410` → the meeting is over/cancelled; `503` → the feature is off; `404`/`401` →
    send them where the page's existing denial handling sends them.
- **Unmanaged session ⇒ nothing changes.** The legacy `meet-join-link` / `meet-no-link`
  branches must render exactly as they do today.
- New `data-testid`s for the button and each result state.
