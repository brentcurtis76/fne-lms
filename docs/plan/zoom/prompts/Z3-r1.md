## PM RULINGS — these are decided. Implement them; do not re-litigate.

**① This chunk ships the PARTICIPANT embed only. `role: 'host'` keeps receiving
`mode: 'link'`.**

Reason, and it is not a shortcut: §9 provisions consultor sessions with
`join_before_host: false`. A host joining `role:1` without a ZAK cannot start the meeting,
so issuing `role:1` here would hand the one person the meeting depends on a join that
fails. ZAK issuance, `role:1`, the §9 per-identity rule (facilitator only on their **own**
mapped host; admin only on org-owned pool identities) and the `zak_issued` audit event are
**chunk Z3-2**. §15's DoD clause this chunk serves is *"School user joins embedded w/o Zoom
account"* — and the school user is the participant.

So: `decision.role === 'host'` → the existing link payload, unchanged, flag or no flag.

**② Flag OFF ⇒ byte-identical Z2 behaviour.** Not "equivalent" — identical. All seven
existing outcomes, both flag states.

**③ Missing or malformed SDK config falls back to LINK mode, never to an error.** If
`ZOOM_SDK_CLIENT_ID`/`ZOOM_SDK_CLIENT_SECRET` are absent, or the signer throws, log the
failure by name only (never a value) and return the link payload. An embed
misconfiguration must never deny a join that link mode could have served. This is the
fail-safe direction and it is deliberate.

**④ `dial_in` stays, on the SDK payload too.** Its rationale is a school internet outage
and that is unchanged by how the video is rendered. Same builder (`buildJoinDialIn`), same
gate, same absent-not-empty semantics.

**⑤ Do not add a numeric `role` field to the wire.** The payload keeps the existing
descriptive `role: 'host' | 'participant'`. The numeric `0` lives inside the signed JWT and
nowhere else — a numeric role on the wire is a value a client could try to echo back, and
§5 says client-supplied role is ignored.

**⑥ `JoinMeetingButton` has no SDK branch yet, and that is fine.** It tests
`payload?.mode === 'link'` (`components/sessions/JoinMeetingButton.tsx:127`), so an
`mode: 'sdk'` response renders its generic failure message. With the flag off by default
nobody reaches it. **Declare this in your report as a known interim** — the client branch
is chunk Z3-3. Do not build it here.
